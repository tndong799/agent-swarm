# Agent Swarm Overlay

A Chrome extension that drops a swarm of neon "AI agents" onto any web page: they scan links and buttons, think out loud, converge on targets, demolish and rebuild the page, run a hacker-movie break-in, and more. **Pure eye candy**: nothing on the page is clicked, typed, collected or sent anywhere.

- **Get it:** [Chrome Web Store](https://chromewebstore.google.com/search/Agent%20Swarm%20Overlay)
- **Privacy policy:** [read it here](https://gist.github.com/tndong799/fafbb441a40288d8a39812906c75b61e)

## Report a bug or suggest a feature

This repository is the public place for feedback.

- 🐞 **Found a bug?** [Report it](https://github.com/tndong799/agent-swarm/issues/new?template=bug_report.yml)
- 💡 **Have an idea?** [Suggest a feature](https://github.com/tndong799/agent-swarm/issues/new?template=feature_request.yml)
- 👍 **Want something that's already requested?** Add a 👍 reaction to the issue instead of opening a new one. That's how features get prioritized.

You need a free GitHub account to open an issue. Please don't include passwords, personal data or private URLs in issues: everything here is public.

Helpful details for bug reports: the extension version (Options page footer or `chrome://extensions`), which mode you were using, and the website where it happened.

## Tiếng Việt

Extension Chrome thả một bầy "AI agent" neon lên bất kỳ trang web nào: quét link, nút bấm, nói ra suy nghĩ, vây mục tiêu, phá dỡ rồi dựng lại trang, chạy màn đột nhập kiểu phim hacker… **Chỉ là hiệu ứng**: không click, không gõ, không thu thập hay gửi dữ liệu nào.

**Báo lỗi hoặc góp ý tính năng:**
